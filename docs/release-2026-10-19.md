## Reproducible checks

Run from the repository root with Node.js:

```sh
node --test tests/*.test.cjs
git diff --check
```

Tests execute the actual inline script using synthetic DOM/storage/clipboard
objects, not a duplicate application. They cover persistence, malformed data,
HTML-sensitive text, invalid input, cent totals, overflow, guide/copy paths and
static offer/link/keyboard contracts. No customer data or payments are used.
